# Project Betty

The planning, record-keeping, and showcase hub for the restomod of Betty, a 1993 Range Rover Classic, from "ran when parked" back to a van-life / adventure rig.

## Language

### The vehicle

**Betty**:
The vehicle: a 1993 Range Rover Classic LWB 4.2, NWS. Daily driver until summer 2025, then parked.
_Avoid_: the car, the Rover, RRC (fine in speech, not in records)

**Vehicle Profile**:
The static facts about Betty: VIN, drivetrain, suspension, known deviations from stock.
_Avoid_: spec sheet, car info

**Phase**:
A stage of the restomod, in order: Recommission (running and driving safely), Refresh (cleanup, rust, seals), Build-out (van-life / adventure rig).
_Avoid_: stage, milestone, step

### The hub

**WorkBook**:
The hub as a whole: every record, Reference, and Showcase about Betty kept in this repo.
_Avoid_: wiki, notes, project docs

**Showcase**:
The public face of the WorkBook: the repo's front page and the Phase pages behind it, written for friends and enthusiasts rather than for working on Betty.
_Avoid_: website, blog, portfolio

**Build Log**:
A dated record of work actually done to Betty.
_Avoid_: journal, diary, changelog

**Plan**:
Work intended for Betty that has not been done yet.
_Avoid_: to-do, roadmap, wishlist

**Case**:
One troubleshooting investigation into a single symptom, accumulating symptoms, hypotheses, tests, and results until resolved.
_Avoid_: issue, problem, ticket (a GitHub issue is not a Case)

**Reference**:
Source material consulted rather than authored: manuals, part numbers, specs, wiring diagrams.
_Avoid_: resources, docs

**Walkthrough**:
A step-by-step procedure authored for Betty specifically, distilled from References and lessons learned; the unit worth carrying offline.
_Avoid_: guide, how-to, procedure

**Area**:
One entry in the single shared list of vehicle systems and build-out zones (e.g. electrical, cooling, sleeping, power) that organises every record in the WorkBook.
_Avoid_: category, system, section

**Inspiration**:
Other people's builds, products, and ideas collected for Betty, grouped by Area.
_Avoid_: mood board, ideas, wishlist
